# 📱 Mobile Python Editor

> 一个运行在手机浏览器里的 Python 编辑器，无需安装、双击即用、完全离线。

## 简介

Mobile Python Editor 是一个**单文件 HTML** 应用，将完整的 Python 运行环境（基于 Pyodide）塞进了一个 HTML 文件里。把它保存到手机，用浏览器打开，你就能随时随地写 Python 代码。

无论你是**编程新手**想利用碎片时间练习，还是**老手**想在手机上快速验证一个想法，它都能满足你。

## ✨ 核心特性

- **单文件即全部**：只有一个 `.html` 文件（约 200KB），无需安装、无需配置、微信直接传。
- **代码编辑增强**：语法高亮、自动缩进、括号自动配对、自定义函数名高亮、代码片段补全。
- **真实运行 Python**：基于 Pyodide（WebAssembly），支持完整的 Python 标准库。
- **实时输入输出**：支持 `input()`，输入内容会以不同颜色回显在输出面板。
- **安全保护**：自动拦截 `time.sleep()` 防止卡死，检测死循环并提醒，支持强制停止。
- **第三方库支持**：通过 `micropip` 可安装 numpy、pandas、matplotlib 等纯 Python 库。
- **文件导入导出**：支持 txt、csv、json、md、xlsx、xls 等格式的导入导出。
- **文档只读视图**：全屏查看虚拟盘里的文档内容。
- **中文报错**：运行出错时显示中英对照的异常名、原因解释和出错行号。

## 🚀 快速开始

1. **下载**：点击仓库页面右上角的 `Code` -> `Download ZIP`，解压后找到 `.html` 文件。
2. **打开**：用手机浏览器（Chrome / Safari / Edge）打开这个 HTML 文件。
3. **运行**：点击右上角 `▶ 运行`，首次需联网加载 Python 环境（约 10MB），之后浏览器会缓存，可离线使用。
4. **开始写代码**：在编辑区输入 Python 代码，点击运行即可。

## 📖 使用说明

### 基本操作

| 功能 | 操作方式 |
|---|---|
| 运行代码 | 点击右上角 `▶ 运行` |
| 保存并运行 | 点击 `💾 保存并运行` |
| 保存文件 | 菜单 `☰` -> 保存（Ctrl+S） |
| 打开文件 | 菜单 `☰` -> 打开文件（Ctrl+O） |
| 新建文件 | 菜单 `☰` -> 新建（Ctrl+N） |
| 另存为 | 菜单 `☰` -> 另存为（Ctrl+Shift+S） |
| 安装第三方库 | 菜单 `☰` -> 📦 安装第三方库 |
| 导出虚拟文件 | 菜单 `☰` -> 📤 导出虚拟文件 |
| 文档视图 | 顶栏 `📄` 按钮 |
| 导入文档 | 顶栏 `📥` 按钮 |

### 编辑技巧

- 输入 `(` `[` `{` `'` `"` 会自动补全另一半
- 行尾是 `:` 时回车自动缩进 4 格
- 输入 2 个以上字母会弹出候选条
- 输入 `except ` 会列出常见异常类型
- 连续输入三个引号会自动补出成对的三引号

### 第三方库安装

在菜单里选择预设库（numpy、pandas、matplotlib、jieba、openpyxl）或自定义输入包名。**注意：仅支持纯 Python 库，含 C 扩展的库（如 scipy、torch）无法安装。**

### 文件导入导出

- **导入**：顶栏 `📥` 按钮，支持 txt、csv、json、md、xlsx、xls（单文件上限 2MB）
- **导出**：菜单 `☰` -> 📤 导出虚拟文件，把虚拟盘里的文件下载到手机

## ⚠️ 已知限制

- **首次运行需联网**：Pyodide 环境约 10MB，之后浏览器缓存，可离线使用。
- **不支持原生文件系统**：`open()` 操作的是内存虚拟盘，刷新页面后文件会丢失。重要文件请用导出功能保存。
- **不支持含 C 扩展的库**：numpy、pandas 部分功能可用，但 scipy、torch 等无法安装。
- **死循环可能卡死页面**：如写了 `while True: pass` 且无 `break`，浏览器主线程会被占满，只能关闭页面重开。程序会在运行前检测并提醒。
- **输入弹窗为系统原生样式**：无法自定义外观，这是浏览器安全限制。
- **本地版与在线版在“装库”上的区别**：
  - **在线版（GitHub Pages）**：支持安装第三方库（numpy、pandas、jieba 等），因为浏览器允许 `https` 协议去外网下载安装包。
  - **本地版（下载的 HTML 文件，`file:///` 协议打开）**：受限于浏览器对本地文件的严格跨域安全策略（CORS），**无法从网络下载并安装第三方库**。本地版仅适合运行 Python 标准库（如 `math`、`random`、`json` 等）或已缓存的代码。如果需要安装第三方库，请直接使用上面的在线链接。
## 🛠️ 技术栈

- **Pyodide** — 将 CPython 编译为 WebAssembly，在浏览器中运行 Python
- **纯前端** — HTML + CSS + JavaScript，无后端依赖
- **WebAssembly** — 提供接近原生的执行性能
